💻 Minha Primeira Aplicação em Java

Este foi o meu primeiro projeto desenvolvido em Java, criado com o objetivo de colocar em prática os conceitos básicos que venho aprendendo na linguagem.

A aplicação é um simulador simples de conta bancária, executado via terminal, onde é possível consultar saldo, transferir valores, receber valores e sair do sistema.

Mais do que o resultado final, este projeto representa meu primeiro contato real com a lógica aplicada em Java.


📚 O que eu aprendi com esse projeto

Durante o desenvolvimento, consegui praticar e entender melhor:

🔹 Estrutura básica de um programa Java

- Criação de classe
- Método principal
- Organização do código

🔹 Tipos de variáveis

- Aprendi a trabalhar com diferentes tipos de dados:
- String (nome do cliente, tipo de conta)
- double (saldo)
- int (opções do menu)

🔹 Entrada de dados com Scanner

- Usei a classe Scanner para permitir que o usuário digitasse valores no terminal, tornando o programa interativo.

🔹 Estruturas condicionais (if / else)

- Implementei validações para:
- Verificar a opção escolhida no menu
- Conferir se há saldo suficiente antes de realizar uma transferência
- Tratar opções inválidas

🔹 Estrutura de repetição (while)

- Utilizei um laço while para manter o sistema rodando até que o usuário escolha sair.
Isso me ajudou a entender melhor como controlar o fluxo de execução de um programa.

🚀 Funcionalidades da aplicação

Ao iniciar, o sistema mostra os dados iniciais do cliente:

Nome
Tipo de conta
Saldo

Depois disso, é exibido um menu com as seguintes opções:

1 - Consultar saldo
2 - Transferir valor
3 - Receber valor
4 - Sair

O usuário pode interagir com o sistema até decidir encerrar.

🎯 Conclusão

Esse projeto marca o início da minha jornada prática com Java.
Mesmo sendo simples, foi fundamental para consolidar conceitos de lógica, estrutura de decisão e interação com o usuário.

É o primeiro passo de muitos que ainda virão 🚀
